## 内容概览

### 第一章：嘉立创 EDA 原理图与 PCB 快速入门

- 理解 EDA（Electronic Design Automation）的基本作用。
- 了解常见 PCB 设计软件和嘉立创 EDA 的基本使用方式。
- 掌握账号、软件、工程和本地文件的基本管理。
- 理解从元器件选型、建立元件库、绘制原理图、生成 PCB 到生产验证的完整流程。
- 掌握 `inch`、`mm` 和 `mil` 等绘制单位。
- 以按键点灯为例学习元器件搜索、放置、连线、属性调整和位号管理。
- 从原理图生成 PCB，完成板框、布局、布线、网络标识、铺铜和丝印。
- 使用 DRC 检查连接错误，并查看 PCB 三维仿真效果。
- 了解 PCB 下单、元器件下单和生产资料准备。

### 第二章：PCB 板制作基础

- 理解 PCB 的定义、作用和现代 PCB 的基本结构。
- 了解 PCB 的高密度化、可靠性、可设计性、可生产性、可测试性、可组装性和可维护性。
- 认识常见 PCB EDA 软件和 PCB 生产过程中的工程资料。
- 掌握器件布局的基本原则：
  - 电气连接紧密的器件进行模块化布局。
  - 接口器件靠近板边并明确方向、电压等级和正负极。
  - 高压、低压、大电流、高频和热源器件合理分区。
  - 去耦电容和滤波电容靠近电源入口或电源转换器件。
- 掌握 PCB 布线的基本原则：
  - 根据电流、频率、板厂工艺和信号完整性要求设置线宽线距。
  - 避免使用小于 90 度的走线拐角。
  - 高速和高频信号线注意间距与干扰控制。

### 第三章：EDA 使用技巧

- 批量扇出添加网络标签和非连接标识。
- 排查铺铜后仍然存在飞线的问题。
- 导入外部图片和 Logo。
- 配置多层板并创建、放置盲埋孔。
- 使用泪滴增强导线与焊盘连接处的机械强度和电气可靠性。
- 区分本地工程文件 `.eprj` 与浏览器工程文件 `.epro`。
- 进行工程文件导入、导出和格式转换。

### 第四章：自定义符号及器件封装

- 在标准模式和专业模式下创建自定义原理图符号。
- 手工绘制封装，以 0805 电容封装为例。
- 使用封装向导生成封装，以 CH340N 为例。
- 进行封装尺寸检查。
- 将原理图符号与个人封装绑定。
- 了解 DIP、QFP、SOP、QFN 和 BGA 等常见芯片封装。
- 了解贴片电阻、电容的英制和公制封装代码。
- 理解线宽、线距和常用 PCB 设计单位。

### 第五章：原理图与 PCB 制作案例

- 可调电阻控制 LED 亮度。
- 独立按键控制 LED 亮灭。
- 使用 74HC138 实现 3-8 译码器电路。
- 使用 74HC245 增强信号驱动能力。
- 使用 LM358 产生 PWM 方波。
- 每个案例均按照元器件选型、原理图绘制、DRC、PCB 转换、布局、布线、铺铜、丝印和检查的流程展开。

### 焊接技能

- 普通电烙铁与恒温电烙铁的使用场景。
- 焊锡丝、合金和助焊剂的基本作用。
- 有铅焊锡与无铅焊锡的区别，以及焊接环境通风要求。
- 使用蓝丁胶固定元器件。
- 使用放大镜检查小尺寸器件和焊点。
- 使用吸锡器完成拆焊和返修。

## 常用工程检查点

| 阶段 | 重点检查内容 |
| --- | --- |
| 元器件选型 | 参数、封装、引脚定义、供货和替代型号 |
| 原理图 | 电源、地、网络名称、引脚连接、位号和未连接引脚 |
| 原理图 DRC | 悬空引脚、短路、未连接网络和规则警告 |
| PCB 布局 | 模块分区、接口方向、高压间距、散热和去耦位置 |
| PCB 布线 | 线宽、线距、转角、回流路径、干扰和大电流承载能力 |
| PCB DRC | 间距、短路、未连接网络、板框和设计规则 |
| 生产准备 | 板层、板框、丝印、封装、Gerber、BOM 和装配要求 |
| 焊接调试 | 极性、焊点、虚焊、连锡、供电电压和通电顺序 |

## 学习建议

1. 先完成按键点灯案例，熟悉原理图到 PCB 的完整闭环。
2. 每次绘制原理图后先完成 DRC，再开始 PCB 布局和布线。
3. 选型时同时查看数据手册、封装尺寸、引脚定义和实际采购信息。
4. 布局时先划分电源、接口、控制、时钟和信号模块，再处理模块间连接。
5. PCB 完成后同时进行 DRC、3D 外观检查、丝印检查和生产资料检查。
6. 焊接前确认元器件方向、极性、封装和焊盘对应关系。
